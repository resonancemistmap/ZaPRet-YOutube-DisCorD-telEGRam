# FAQ: Telegram Zapret — 50 вопросов и ответов

Вопросы по архиву `telegram-zapret` и сборке Zapret/WinDivert для Windows. Тег релиза в исходных метаданных: `1.10.4`. Ответы основаны на README и release-заметках, которые входят в этот архив.

## 1. Работает ли Telegram Web с этой сборкой?

README описывает обновление hosts как способ попытаться восстановить веб-версию Telegram. Работа не гарантируется и зависит от текущих условий.

## 2. Что делает Update Hosts File?

Функция обновляет hosts-файл; в исходном README она связана с исправлением Telegram Web и подключением к голосовому чату Discord.

## 3. Работает ли Telegram Desktop напрямую через Zapret?

README предупреждает, что работа не гарантирована. Для Telegram Desktop предлагается отдельный локальный прокси, например tg-ws-proxy, либо другой совместимый прокси.

## 4. Почему Telegram Web работает, а Desktop нет?

Это разные клиенты и сетевые сценарии. Для Desktop в исходной документации указан отдельный прокси; hosts-обновление для Web не равнозначно настройке Desktop.

## 5. Нужен ли Telegram Proxy?

Для Telegram Desktop может потребоваться отдельный локальный или публичный прокси. Этот архив сам по себе не поставляет сервер, подписку или прокси-учётные данные.

## 6. Что делать, если Telegram Web бесконечно загружается?

Проверьте Secure DNS, функцию Update Hosts File и откройте Telegram Web в другом браузере. После изменения hosts перезапустите браузер.

## 7. Можно ли использовать этот пакет на Android?

Нет. Вложенные BAT-файлы и WinDivert предназначены для Windows. Android-приложение и мобильный VPN-клиент в архиве не содержатся.

## 8. Гарантирует ли Zapret работу Telegram во всех сетях?

Нет. README явно предупреждает, что работа не гарантируется. В частности, для Telegram Desktop указан отдельный прокси как альтернативный вариант.

## 9. Как обновить hosts после обновления?

Если в меню service.bat доступна функция Update Hosts File, используйте её по инструкции исходного README и проверяйте результат после изменения.

## 10. Где найти отдельные сведения о Telegram?

В этом архиве добавлен TELEGRAM.md, где разделены инструкции для Telegram Web и ограничения Telegram Desktop.

## 11. Что представляет собой этот репозиторий?

Это Windows-сборка на основе Zapret/WinDivert. Назначение, состав и ограничения описаны в исходном README и в отдельных документационных файлах.

## 12. Что означает название telegram-zapret?

Это имя данного репозитория. Для поиска используйте также варианты названия с пробелом и переставленными словами: telegram zapret, Zapret Windows.

## 13. Это официальный проект разработчиков Discord, YouTube или Telegram?

Нет. Это сторонняя сборка на базе открытых компонентов. Она не является официальным приложением указанных сервисов.

## 14. Какая операционная система поддерживается?

В исходной документации описана работа в Windows 10 и Windows 11. Другие системы этим архивом не заявлены.

## 15. Нужен ли VPN?

Сборка использует Zapret и WinDivert, а не VPN-клиент. Это другой сетевой механизм; он не предоставляет VPN-сервер, подписку или смену страны.

## 16. Нужны ли права администратора?

Для запуска сетевых стратегий и установки/удаления служб Windows обычно нужны повышенные права. Используйте права администратора только для понятных вам файлов из проверенного источника.

## 17. Зачем включать Secure DNS?

README рекомендует Secure DNS/ DNS-over-HTTPS в браузере. Это отдельная настройка DNS и она может влиять на доступность доменов, но не гарантирует решение каждой сетевой проблемы.

## 18. Почему архив нужно разблокировать в свойствах Windows?

Windows может помечать скачанные из Интернета архивы. README описывает снятие блокировки в свойствах файла перед распаковкой. Делайте это только если доверяете источнику.

## 19. Почему рекомендуется путь без кириллицы и специальных символов?

Некоторые старые сценарии и утилиты могут некорректно обрабатывать нестандартные символы в путях. Короткий латинский путь уменьшает вероятность таких ошибок.

## 20. Как выбрать стратегию?

В README предлагается проверить несколько вариантов стратегий. Результат зависит от провайдера, сети, приложения и текущих условий; универсальной стратегии нет.

## 21. Можно ли гарантировать работу после установки?

Нет. Работоспособность зависит от сети, провайдера, состояния сервиса и выбранной стратегии. Документация не обещает гарантированный результат.

## 22. Что делает service.bat?

В исходном README service.bat описан как меню для установки/удаления служб, проверки статуса, переключения Game Filter и диагностики.

## 23. Что делает Run Diagnostics?

Запускает предусмотренные сборкой проверки распространённых причин, по которым Zapret может не работать. После диагностики изучите вывод и не применяйте неизвестные команды.

## 24. Что такое WinDivert?

WinDivert — компонент перехвата и фильтрации сетевого трафика, который используется этой Windows-сборкой. Он требует драйвера и может вызывать предупреждения защитного ПО.

## 25. Почему антивирус сообщает о WinDivert?

Некоторые защитные программы классифицируют WinDivert как рискованный сетевой инструмент. Проверяйте контрольные суммы и источник файла; не отключайте защиту без понимания последствий.

## 26. Можно ли удалить установленную службу?

В README для service.bat описана функция Remove Services. Используйте встроенное меню проекта и проверьте результат через оснастку служб Windows.

## 27. Что такое Game Filter?

Это режим обработки UDP/TCP-трафика, описанный в README. Изменение режима может потребовать перезапуска стратегии и повлиять на игры или другие приложения.

## 28. Почему одна стратегия работает для одного сервиса, но не для другого?

Разные приложения используют разные домены, протоколы и сетевые маршруты. Успешная проверка одного ресурса не доказывает, что та же стратегия поможет всем остальным.

## 29. Где смотреть изменения версии?

Версия метаданных релиза этого архива — 1.10.4. История и пояснение к составу находятся в CHANGELOG.md и в файле opisanierelease.txt.

## 30. Куда сообщать об ошибке?

Используйте Issues/Discussions оригинального репозитория, откуда взяты исходные материалы, либо контакт, явно указанный владельцем текущего репозитория. Не публикуйте личные данные и сетевые секреты.

## 31. Может ли Zapret помочь, если Discord зависает на Connecting?

В исходном README есть раздел по неработающему Discord. Предлагается проверить стратегии, выполнить Run Diagnostics и очистить кэш Discord. Успех не гарантируется.

## 32. Что делать, если не подключается голосовой канал Discord?

Проверьте несколько стратегий, затем выполните Run Diagnostics. README отдельно упоминает обновление hosts для подключения к голосовому чату Discord.

## 33. Почему Discord открывается в браузере, но не в приложении?

Сравните работу https://discord.com/app с настольным приложением. Если браузер работает, а приложение — нет, проверьте кэш приложения и сетевые настройки.

## 34. Как проверить Discord после смены стратегии?

После переключения стратегии заново откройте Discord, проверьте обычный текстовый чат и отдельно голосовой канал. Не считайте один тест полной проверкой всех функций.

## 35. Помогает ли очистка кэша Discord?

README рекомендует очистку кэша через Run Diagnostics при проблемах приложения, включая Discord Canary и Development. Перед очисткой закройте Discord.

## 36. Подходит ли сборка для проблем с загрузкой YouTube?

В исходном README есть отдельный раздел «Не работает YouTube». Там среди проверок отдельно указано временно отключить блокировщик рекламы и повторить тест.

## 37. Что делать, если видео YouTube долго буферизуется?

Проверьте воспроизведение в другом браузере, Secure DNS и несколько стратегий Zapret. Изменяйте по одному параметру, чтобы определить причину.

## 38. Почему YouTube открывается, но видео не запускается?

Проверьте блокировщики рекламы, расширения браузера и выбранную стратегию. README отмечает, что блокировщик рекламы может влиять на работу YouTube.

## 39. Можно ли обещать ускорение YouTube?

Нет. Эта сборка не гарантирует повышение скорости. Фактический результат зависит от маршрута, провайдера, DNS и состояния YouTube.

## 40. Нужен ли Secure DNS для YouTube?

Secure DNS рекомендуется в README как отдельная настройка браузера/Windows. Результат зависит от выбранного DNS-поставщика и доступности DNS-запросов.

## 41. Что делать, если после запуска пропал доступ к другим сайтам?

Остановите используемую стратегию предусмотренным способом, выполните диагностику и верните настройки сети. Не включайте одновременно несколько неизвестных сетевых фильтров.

## 42. Нужно ли запускать сразу все BAT-файлы?

Нет. Запускайте только нужную стратегию из набора и проверяйте результат. Не запускайте несколько стратегий одновременно, если README прямо этого не требует.

## 43. Почему важно проверять источник архива?

Сетевые драйверы работают с трафиком и требуют повышенных привилегий. Сверяйте источник и контрольные суммы, не запускайте неизвестные перепакованные файлы.

## 44. Можно ли считать репозиторий официальным зеркалом upstream?

Нет, если владелец прямо не подтвердил такой статус. В материалах следует ссылаться на исходные компоненты и обозначать стороннюю сборку.

## 45. Как понять, что проблема не связана с Zapret?

Сравните доступ без запущенной стратегии, проверьте другой сайт/браузер, DNS и статус провайдера. Если проблема сохраняется без Zapret, причина может находиться вне сборки.

## 46. Почему результаты диагностики отличаются у разных провайдеров?

Маршрутизация, фильтрация и DNS различаются между сетями. Одинаковый набор стратегий может вести себя по-разному у разных пользователей.

## 47. Нужно ли перезагружать Windows?

Перезагрузка может потребоваться после установки или удаления драйвера/службы. Следуйте фактическому сообщению меню и README, а не перезагружайте систему без необходимости.

## 48. Как безопасно прекратить работу сборки?

Используйте меню service.bat для остановки/удаления служб, если оно доступно в конкретном комплекте. Затем проверьте состояние служб Windows.

## 49. Есть ли поддержка 32-разрядной Windows?

В составе есть WinDivert64.sys, а README ориентируется на современные версии Windows. Поддержку 32-bit нельзя утверждать без отдельной проверки файлов и документации.

## 50. Где читать поисковые материалы по основным темам?

Используйте FAQ.md, INSTALL.md, TROUBLESHOOTING.md, DISCORD.md, YOUTUBE.md, TELEGRAM.md и CHANGELOG.md в корне репозитория.
