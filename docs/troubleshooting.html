Discord Zapret: решение проблем и диагностика

Руководство составлено по инструкциям в репозитории JuniorClient/discordzapret. Проверяйте стратегии по одной и сравнивайте результат. После изменения фильтров перезапускайте выбранную стратегию.

1. После запуска general*.bat ничего не происходит

  • Проверьте, появился ли процесс winws.exe в списке процессов/системной области.
  • Запустите service.bat → Run Diagnostics.
  • Выполните Run Tests и проверьте другие стратегии.
  • Если окно сразу закрывается, запустите файл из командной строки, чтобы увидеть сообщения об ошибке.

2. Ни одна стратегия не подходит

  1. Проверьте Secure DNS.
  2. Запустите service.bat → Run Diagnostics.
  3. Убедитесь, что домен/адрес, который вы проверяете, включён в список целей или соответствующий список доменов/IP.
  4. Попробуйте другие стратегии, например варианты ALT и FAKE.
  5. Если сохраняется системная сетевая проблема, исходный README предлагает сетевой сброс. Выполняйте его только из командной строки администратора и после сохранения индивидуальных сетевых настроек:
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns

После команд перезагрузите компьютер. Сброс может затронуть пользовательские сетевые настройки и прокси.

3. Discord не подключается или голосовой чат остаётся на Connecting

  • Проверьте Secure DNS.
  • Проверьте веб-версию: https://discord.com/app.
  • Запустите service.bat → Run Diagnostics и выполните очистку кэша Discord, если такой пункт предлагается.
  • Проверьте другую стратегию: одна и та же конфигурация может по-разному работать для YouTube и Discord.
  • Для бесконечного подключения к голосовому чату проверьте раздел Update Hosts File.

4. YouTube не открывается или медленно загружается

  • Убедитесь, что настроен Secure DNS.
  • Временно проверьте работу без блокировщика рекламы как диагностический тест.
  • Попробуйте другие стратегии.
  • См. отдельный материал про YouTube.

5. Telegram Web не подключается

  • Откройте service.bat → Update Hosts File.
  • Если утилита предлагает обновить hosts вручную, скопируйте показанный текст.
  • Откройте файл hosts в текстовом редакторе, запущенном от имени администратора, добавьте или замените соответствующие строки и сохраните файл.
  • Подробности — в TELEGRAM.md.

6. Telegram Desktop не работает

Работа Telegram Desktop в этой сборке не гарантируется. README предлагает использовать отдельный локальный прокси tg-ws-proxy или MTProto-прокси. Это отдельные инструменты, не встроенная функция данного архива.

7. Игра или приложение перестали работать

  • Проверьте Game Filter и IPSet Filter в service.bat.
  • Для диагностики начните с более ограниченного режима. В README предупреждается, что IPSet Filter = any может вызвать проблемы с открытием многих сайтов; не оставляйте его включённым без необходимости.
  • После изменения режима перезапустите стратегию.

8. Антивирус сообщает о WinDivert

README объясняет, что WinDivert используется для перехвата и фильтрации трафика и может классифицироваться некоторыми антивирусами как RiskTool/PUA. Скачивайте архив только из проверенного репозитория. Не отключайте антивирус целиком ради запуска неизвестной сборки.

9. WinDivert остался в службах после удаления

Исходная инструкция предлагает выяснить имя службы в командной строке администратора:

driverquery | find "Divert"

Только после проверки точного имени можно остановить и удалить найденную службу:

sc stop ИМЯ_НАЙДЕННОЙ_СЛУЖБЫ
sc delete ИМЯ_НАЙДЕННОЙ_СЛУЖБЫ

Не копируйте команды с выдуманным именем.

10. Когда нужна чистая переустановка

Сохраните собственные списки и настройки, удалите службу через service.bat → Remove Services, выполните диагностику, удалите старую папку, скачайте архив из последнего релиза и распакуйте его в новый простой путь без кириллицы и специальных символов. Затем проверьте стратегии заново.

Куда сообщить об ошибке

Откройте Issues или Discussions. Укажите версию Windows, тип сети, выбранную стратегию, какой сервис не работает и результат диагностики. Не прикладывайте пароли, токены и персональные данные.
