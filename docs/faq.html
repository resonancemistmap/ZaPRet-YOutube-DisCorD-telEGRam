Discord Zapret: FAQ — 50 вопросов и ответов

Этот раздел отвечает на практические вопросы о сборке JuniorClient/discordzapret: Discord, YouTube, Telegram Web, Secure DNS, стратегиях, service.bat, WinDivert и Windows. Это сторонняя сборка на основе zapret, а не официальный продукт Discord, YouTube или Telegram. Работа стратегий не гарантируется для каждой сети.

Основные страницы: репозиторий, последний релиз, установка, диагностика, YouTube, Telegram, история версий.

1. Что такое Discord Zapret / discordzapret?

discordzapret — опубликованная в этом репозитории сборка на основе zapret для Windows. В ней есть несколько вариантов стратегий, вспомогательный service.bat, диагностика и тесты. Это не официальный клиент Discord и не VPN-сервис.

2. Где находится оригинальный репозиторий JuniorClient/discordzapret?

Оригинальная страница проекта находится здесь: https://github.com/JuniorClient/discordzapret. Проверяйте владельца и название репозитория перед загрузкой файлов.

3. Является ли этот репозиторий официальным проектом Discord?

Нет. Это сторонняя сборка на основе zapret. Она не создана, не поддерживается и не одобрена Discord, YouTube или Telegram.

4. Для чего предназначен этот пакет?

Пакет предназначен для тестирования сетевых стратегий zapret в Windows и диагностики проблем доступа к отдельным сервисам. В README отдельно описаны сценарии Discord, YouTube и Telegram Web.

5. Работает ли сборка с Discord Desktop?

В документации рассматриваются приложение Discord, очистка его кэша и подключение к голосовому чату. Совместимость не гарантируется для каждой сети и каждой стратегии.

6. Можно ли проверить Discord в браузере?

Да. Откройте https://discord.com/app. Если веб-версия работает, а приложение нет, проверьте кэш приложения через service.bat → Run Diagnostics.

7. Что делать, если Discord застрял на Connecting?

Сначала проверьте Secure DNS и попробуйте разные стратегии. Если проблема касается голосового подключения, документация также предлагает service.bat → Update Hosts File и проверку файла hosts.

8. Поддерживаются ли Windows 10 и Windows 11?

Документация сборки ориентирована на Windows 10 и Windows 11. Для обычного использования скачайте последнюю версию из Releases и следуйте инструкции INSTALL.md.

9. Подходит ли пакет для Windows x64?

Метаданные опубликованной страницы указывают Windows 10/11 и x64. Не делайте вывод о поддержке других архитектур без проверки состава конкретного релиза.

10. Это VPN?

Нет. Пакет не является VPN-клиентом и не предоставляет VPN-сервер или туннель. Он использует сетевые стратегии zapret и компоненты WinDivert.

11. Меняет ли zapret IP-адрес пользователя?

В документации не заявлена функция смены внешнего IP-адреса. Не рассматривайте пакет как средство смены IP, анонимизации или защиты всего интернет-трафика.

12. Гарантирует ли Discord Zapret восстановление доступа?

Нет. README прямо предупреждает, что стратегии могут переставать работать и результат зависит от условий сети. Нужно проверить несколько стратегий и диагностику.

13. Где скачать последнюю версию?

Открывайте только страницу Releases этого репозитория: https://github.com/JuniorClient/discordzapret/releases/latest. Проверяйте, что владелец — JuniorClient и репозиторий — discordzapret.

14. Как называется архив в текущем релизе?

В приложенном исходном архиве и описании релиза указан asset zapret-discord-youtube.zip. В старом тексте Release ошибочно упоминается RAR; ориентируйтесь на фактическое расширение файла в Assets.

15. Какая версия указана в релизе?

В предоставленном репозитории указан тег 1.10.4. Всегда сверяйте тег на странице Releases: он может измениться после публикации этого SEO-пакета.

16. Нужно ли разблокировать скачанный ZIP в Windows?

Откройте свойства скачанного архива. Если Windows показывает флажок «Разблокировать», установите его и нажмите «Применить». В исходной инструкции указано, что при использовании 7-Zip или PeaZip этот шаг можно пропустить.

17. В какую папку распаковывать архив?

Распакуйте содержимое в путь без кириллицы и специальных символов. В документации также рекомендуется избегать сложных путей и лишних пробелов.

18. Что такое Secure DNS?

Secure DNS — это защищённый способ выполнения DNS-запросов, например DNS-over-HTTPS. README рекомендует включить Secure DNS перед тестированием стратегий.

19. Как включить Secure DNS в Chrome?

Откройте настройки безопасности Chrome, найдите параметр «Использовать безопасный DNS» и выберите поставщика, отличный от варианта по умолчанию. Названия пунктов могут меняться между версиями браузера.

20. Как включить DNS over HTTPS в Firefox?

В настройках Firefox откройте параметры DNS over HTTPS, выберите подходящий режим защиты и при необходимости укажите URL DNS-провайдера вручную. В README приведён пример https://dns.google/dns-query.

21. Можно ли включить Secure DNS в Windows 11?

Да, README указывает на встроенную настройку Secure DNS в Windows 11. Путь к параметру зависит от версии Windows; используйте актуальную инструкцию Microsoft или справочный материал, на который ссылается README.

22. Зачем на роутере Keenetic нужен режим «Транзит запросов»?

В README отмечено, что отключение этой опции может создавать проблемы при настройке и использовании Secure DNS на компьютере через роутер Keenetic.

23. Для чего нужны файлы general*.bat?

Файлы general*.bat запускают отдельные стратегии вручную. Их можно использовать для тестирования, чтобы определить, какая конфигурация подходит вашей сети.

24. Что означают варианты ALT и FAKE?

Это названия вариантов стратегий, присутствующих в сборке. Не существует универсально лучшего варианта: проверяйте стратегии по очереди и выбирайте работающую в конкретной сети.

25. Для чего нужен service.bat?

service.bat содержит меню управления: установка и удаление службы, проверка статуса, переключение Game Filter и IPSet Filter, обновление IPSet и hosts, диагностика и тестирование стратегий.

26. Как проверить доступные стратегии?

Откройте service.bat → Run Tests → Standard tests и запустите доступный набор тестов, например All configs, если этот пункт присутствует в вашей версии меню. Проверка использует список целей из utils/targets.txt.

27. Что делает Run Diagnostics?

Run Diagnostics проверяет распространённые причины, по которым zapret может не работать. В документации также упоминается возможность очистить кэш Discord.

28. Как установить стратегию в автозапуск?

Сначала вручную найдите подходящую стратегию. Затем откройте service.bat → Install Service и выберите нужный вариант. В меню service.bat отображается установка стратегии в службы Windows.

29. Как удалить установленную службу?

Откройте service.bat и выберите Remove Services. Перед переустановкой документация рекомендует удалить прежнюю службу и проверить систему через Run Diagnostics.

30. Что показывает Check Status?

Этот пункт отображает статус обхода и связанных служб, включая стратегию, установленную в автозапуск, и WinDivert.

31. Как обновить IPSet?

В service.bat выберите Update IPSet List. Команда предназначена для обновления ipset-all.txt версией из репозитория.

32. Что означает IPSet Filter?

Этот переключатель задаёт, какие IP-адреса попадают под проверку: none — никакие, loaded — адреса сверяются со списком, any — под фильтр попадает любой IP.

33. Что делает Game Filter?

Game Filter предназначен для режима обработки игрового трафика и других сервисов, использующих UDP и TCP на портах выше 1023. Изменение режима может повлиять на работу отдельных приложений.

34. Нужно ли перезапускать стратегию после изменения фильтра?

Да. В README прямо указано, что после переключения Game Filter или связанного режима требуется перезапуск стратегии.

35. Что делать, если general*.bat запускается, но эффекта нет?

Проверьте, появляется ли процесс winws.exe, запустите Run Diagnostics и выполните Run Tests. Если ни одна стратегия не подходит, сначала проверьте Secure DNS и сетевые настройки.

36. Что делать, если ни одна стратегия не работает?

Запустите командную строку от имени администратора и выполните сетевой сброс только если понимаете последствия: netsh winsock reset, netsh int ip reset all, netsh winhttp reset proxy, ipconfig /flushdns. Затем перезагрузите компьютер. Перед этим сохраните индивидуальные сетевые настройки.

37. Почему YouTube работает, а Discord нет?

README предупреждает, что одна стратегия может работать для YouTube и не работать для Discord. Проверяйте Discord отдельно и перебирайте доступные стратегии.

38. Что проверить, если YouTube не загружается?

Проверьте Secure DNS, временно протестируйте работу без блокировщика рекламы и попробуйте другие стратегии. Это рекомендации из README, а не гарантия устранения проблемы.

39. Помогает ли сборка при замедлении YouTube?

В README YouTube указан среди сервисов, для которых проверяются стратегии zapret. Фактический результат зависит от сети, провайдера, DNS и выбранной стратегии.

40. Нужно ли отключать блокировщик рекламы для проверки YouTube?

README советует временно проверить работу без блокировщика рекламы. Это диагностический тест; не требуется оставлять защиту отключённой постоянно.

41. Есть ли у проекта отдельное расширение YouTube?

В предоставленных файлах не описано браузерное расширение. Речь идёт о сетевых стратегиях zapret и настройках Secure DNS.

42. Поддерживается ли Telegram Web?

В README есть отдельный сценарий для Telegram Web: service.bat → Update Hosts File. Если файл hosts требует обновления вручную, следуйте шагам из TELEGRAM.md.

43. Поддерживается ли Telegram Desktop напрямую этой сборкой?

В README прямо сказано, что работа не гарантирована. Для Telegram Desktop предлагается использовать отдельный локальный прокси, например tg-ws-proxy, или MTProto-прокси.

44. Что такое tg-ws-proxy и где его взять?

Это отдельный проект, указанный в README как вариант локального прокси для Telegram Desktop: https://github.com/Flowseal/tg-ws-proxy. Он не является встроенной функцией данного архива.

45. Как обновить hosts для Telegram Web?

Откройте service.bat → Update Hosts File. Если утилита показывает обновлённый текст для hosts, скопируйте его и добавьте в системный файл hosts с помощью текстового редактора, запущенного от имени администратора.

46. Можно ли утверждать, что Telegram обходится без прокси?

Нет. Для Telegram Web в README предлагается обновление hosts, а для Telegram Desktop — отдельный локальный или MTProto-прокси. Универсальная работа Telegram без прокси не обещается.

47. Почему антивирус предупреждает о WinDivert?

README указывает, что WinDivert — драйвер для перехвата и фильтрации трафика, который некоторые антивирусы относят к RiskTool/PUA. Скачивайте файлы только из проверенного источника и не отключайте защиту без понимания риска.

48. Что делать, если античит реагирует на WinDivert?

В README приведена отдельная инструкция zapret-win-bundle/windivert-hide. Совместимость с конкретным античитом не гарантируется; соблюдайте правила игры и её античита.

49. Что делать, если после удаления осталась служба WinDivert?

README предлагает проверить имя службы командой driverquery | find "Divert", затем при необходимости остановить и удалить именно найденную службу командами sc stop и sc delete из командной строки администратора. Не подставляйте случайное имя службы.

50. Где сообщить об ошибке или задать вопрос?

Для ошибки используйте Issues: https://github.com/JuniorClient/discordzapret/issues. Для обсуждения и вопросов можно открыть Discussions: https://github.com/JuniorClient/discordzapret/discussions. В сообщении укажите Windows, провайдера/тип сети, стратегию и результат Run Diagnostics; не публикуйте личные данные.
