Установка Discord Zapret на Windows 10 и Windows 11

Это руководство относится к сборке JuniorClient/discordzapret. Пакет предназначен для Windows; актуальный архив и тег проверяйте на странице релизов. Сборка не является VPN и не гарантирует одинаковый результат у всех провайдеров.

Перед установкой

  • Используйте Windows 10 или Windows 11; в метаданных текущей сборки указана архитектура x64.
  • Скачивайте архив только со страницы релиза указанного репозитория.
  • При необходимости заранее настройте Secure DNS в браузере или Windows. README рекомендует не использовать DNS-поставщика по умолчанию, если с ним есть проблемы.
  • Не запускайте неизвестные копии из случайных Telegram-каналов, видеороликов или сторонних сайтов. В README отдельно предупреждается о поддельных страницах проекта.

Шаг 1. Скачать архив

  1. Откройте последний релиз.
  2. В Assets выберите фактический ZIP-архив. В исходном пакете указан файл zapret-discord-youtube.zip; ориентируйтесь на имя и расширение, реально показанные в релизе.
  3. Дождитесь завершения загрузки. Не переименовывайте архив в RAR: это ZIP-файл.

Шаг 2. Разблокировать и распаковать

  1. Если Windows показывает флажок «Разблокировать» в свойствах ZIP-файла, установите его и нажмите «Применить». В исходном README этот шаг разрешается пропустить при использовании 7-Zip или PeaZip.
  2. Распакуйте архив в папку с путём без кириллицы и специальных символов.
  3. Не запускайте файлы прямо из окна архиватора.

Шаг 3. Включить Secure DNS

  • Chrome: настройки безопасности → «Использовать безопасный DNS» → выберите подходящего поставщика.
  • Firefox: настройки DNS over HTTPS → выберите режим и поставщика; README приводит пример https://dns.google/dns-query.
  • Windows 11: можно использовать встроенную настройку Secure DNS в системных параметрах, если она доступна для выбранного интерфейса.
  • Keenetic: README отмечает, что отключённый «Транзит запросов» может мешать настройке Secure DNS на компьютере.

Названия настроек меняются между версиями ОС и браузеров. Не копируйте DNS-адреса из случайных инструкций, если не доверяете их оператору.

Шаг 4. Проверить стратегии

  1. Запустите service.bat с необходимыми правами администратора.
  2. Откройте Run Tests.
  3. Запустите Standard tests; в некоторых версиях меню доступен набор All configs.
  4. Дождитесь завершения проверки и сравните результаты.
  5. Если нужно, вручную проверьте отдельные general*.bat — они запускают стратегии по одной.

Не существует универсально лучшей стратегии: совместимость зависит от провайдера, сети, DNS и текущего состояния фильтрации.

Шаг 5. Включить автозапуск (необязательно)

Когда вы нашли рабочую стратегию, откройте service.bat → Install Service и выберите нужный вариант. Для удаления используйте Remove Services. После переключения Game Filter или IPSet Filter перезапустите стратегию.

После установки

  • Проверьте Discord в приложении и по адресу https://discord.com/app.
  • Если голосовой чат зависает на подключении, смотрите инструкцию по hosts и диагностику.
  • Если не загружается YouTube, смотрите отдельную инструкцию.
  • Для Telegram Desktop README рекомендует отдельный локальный прокси; данная сборка не заменяет tg-ws-proxy.
