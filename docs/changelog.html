Discord Zapret — история версий

Этот файл фиксирует только сведения, которые есть в переданном архиве и на опубликованной странице релиза. Неизвестные изменения между версиями не додумываются.

1.10.4 — текущий тег исходного релиза

  • В репозитории и переданном архиве указан тег 1.10.4.
  • На странице GitHub этот релиз отмечен датой публикации 11 ноября 2026 года.
  • В опубликованном описании релиза перечислены изменения исходного проекта Flowseal: отправка fake-пакетов для неизвестных TCP-протоколов в режиме GameFilter TCP; обновления стратегий SIMPLE FAKE, EXP и ALT1; исправления; обновление IPSet; очистка кэша Discord Canary и Discord Development через service.bat.
  • В release notes отдельно предупреждается, что GameFilter TCP может как помочь отдельным сервисам и играм, так и нарушить уже работавшее подключение. Используйте эту настройку осторожно.

Примечание о нумерации: текст опубликованного релиза завершается ссылкой на upstream-сравнение 1.10.0...1.10.1, хотя тег текущего репозитория — 1.10.4. Поэтому это описание отражает опубликованный список изменений и его upstream-ссылку, но не является полной историей каждого промежуточного тега локальной сборки.

Подтверждённые функции сборки по документации

  • Ручной запуск стратегий через general*.bat.
  • Управление службами и настройками через service.bat.
  • Тестирование стратегий и диагностика.
  • Обновление IPSet и hosts.
  • Переключатели Game Filter и IPSet Filter.

Как читать следующие обновления

Для каждой новой версии указывайте тег, дату, фактический список изменений, изменённые файлы и известные ограничения. Не переносите список изменений старого upstream-релиза на новый локальный тег без проверки.
