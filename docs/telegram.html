Telegram Zapret: Telegram Web, Telegram Desktop и hosts

Важно различать Telegram Web и Telegram Desktop. В исходном README для них описаны разные способы решения проблем. Эта сборка не является универсальным Telegram-прокси и не гарантирует работу Telegram Desktop.

Telegram Web: обновление hosts

В README указана такая последовательность:

  1. Распакуйте архив и откройте service.bat.
  2. Выберите Update Hosts File.
  3. Если содержимое hosts требует ручного обновления, скопируйте текст, который показала утилита.
  4. Откройте системный файл hosts в текстовом редакторе, запущенном от имени администратора.
  5. Добавьте скопированные строки в конец файла либо замените устаревшие строки, если вы ранее применяли аналогичную настройку.
  6. Сохраните файл и повторно проверьте Telegram Web. Убедитесь, что изменения действительно записались.

Если Telegram Web по-прежнему не подключается, проверьте, что файл hosts сохранён с административными правами и не содержит конфликтующих старых записей. Не скачивайте готовые hosts-файлы из неизвестных источников.

Telegram Desktop: отдельный прокси

В исходном README прямо сказано, что работа Telegram Desktop через эту сборку не гарантируется. В качестве альтернативы указаны:

  • Flowseal/tg-ws-proxy — отдельный локальный прокси-проект.
  • MTProto-прокси — отдельный способ подключения, который пользователь выбирает и проверяет самостоятельно.

Эти инструменты не входят в данный архив и не должны описываться как встроенная функция JuniorClient/discordzapret. Проверяйте источник и доверяйте только известным провайдерам прокси.

Telegram и голосовой чат Discord

В README описан общий сценарий service.bat → Update Hosts File для Telegram Web и ситуации, когда Discord Voice застревает на подключении. Если проблема сохраняется, проверьте Discord в браузере, очистку кэша через Run Diagnostics и другую стратегию.

Поисковые темы и формулировки

Эта инструкция охватывает: Telegram Web Windows, Telegram не подключается, Telegram Web не открывается, Telegram hosts Windows, Update Hosts File, service.bat hosts, Telegram Desktop proxy, tg-ws-proxy, MTProto proxy, Discord Voice Connecting, голосовой чат Discord не подключается. Наличие этих тем не означает, что Telegram Desktop-прокси включён в архив.
