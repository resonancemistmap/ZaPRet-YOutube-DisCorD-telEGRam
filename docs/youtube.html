YouTube Zapret: настройка и решение проблем с загрузкой YouTube

В репозитории JuniorClient/discordzapret есть стратегии zapret, которые можно проверить при сетевых проблемах с YouTube. Это не отдельное приложение YouTube, не браузерное расширение и не гарантия обхода замедления. В исходном README предлагается включить Secure DNS и протестировать другие стратегии.

Перед тестированием YouTube

  1. Настройте Secure DNS в используемом браузере или Windows. Примеры настройки Chrome и Firefox приведены в INSTALL.md.
  2. Откройте service.bat → Run Tests → Standard tests, если этот пункт доступен в вашей версии.
  3. Проверьте несколько стратегий general*.bat. Одна конфигурация может работать с YouTube, но не подходить для Discord или других сервисов.

Если YouTube не открывается

  • Проверьте, что Secure DNS включён и выбранный DNS-провайдер доступен из вашей сети.
  • Временно отключите блокировщик рекламы только на время диагностической проверки. Если поведение не меняется, верните прежние настройки защиты.
  • Попробуйте другие стратегии и сравните результат.
  • Запустите service.bat → Run Diagnostics и проверьте сообщения диагностики.

Если YouTube тормозит, но сайт открывается

Проверьте, одинаково ли ведут себя главная страница, поиск и воспроизведение видео. Не делайте вывод о работе стратегии по одной странице. Сравнивайте результаты на одной сети и в одинаковых условиях.

Связь YouTube и Discord

README рекомендует сначала определить стратегию, на которой открывается YouTube, и затем проверить Discord с этой конфигурацией. При этом прямо предупреждается: стратегия, работающая для YouTube, может не работать для Discord. Поэтому каждый сервис проверяйте отдельно.
